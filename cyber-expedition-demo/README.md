# Киберэкспедиция — локальная демоверсия

Интерактивный маршрут для занятия по цифровой безопасности. Ребёнок последовательно проходит четыре района: проверяет фото перед публикацией, собирает учебную парольную фразу, распознаёт ловушки в сообщениях и тренирует безопасные ответы в чате.

## Установка и запуск

```bash
cd cyber-expedition-demo
npm install
npm start
```

Откройте `http://127.0.0.1:4177/`.

Файл `.env` не используется. Сервер по умолчанию доступен только на локальном адресе `127.0.0.1:4177`; при необходимости другой порт можно передать через системную переменную `PORT`.

## Два режима

- **Начать экспедицию** — полный детский маршрут: Зеркальный сад → Замок секретов → Ярмарка ловушек → Станция общения. Районы открываются по порядку, а финал чата показывает собранный щит `4/4`.
- **Режим просмотра для взрослого** — быстрая навигация по шести рабочим назначениям: домой, карта, зеркало, замки, ловушки и чат. Задания открываются с необходимыми учебными предпосылками.

## Опциональные локальные медиа

Демо полностью работает без медиафайлов и показывает иллюстрированные заглушки. Для каждого из пяти слотов можно положить в `media/` локальный MP4-ролик, WebP-постер и русские VTT-субтитры либо только MP3-аудиоверсию, затем указать относительные пути в `src/content.js`. У проигрывателей есть элементы управления, а автозапуск не используется.

| Слот | Видео | Русские субтитры | Содержание |
| --- | --- | --- | --- |
| Вступление | `city-intro.mp4` | `city-intro.ru.vtt` | Знакомство с кибергородом |
| Зеркальный сад | `mirror-post.mp4` | `mirror-post.ru.vtt` | Безопасная публикация фото |
| Замок секретов | `secret-locks.mp4` | `secret-locks.ru.vtt` | Парольная фраза и второй фактор |
| Ярмарка ловушек | `trick-market.mp4` | `trick-market.ru.vtt` | Признаки подозрительных сообщений |
| Станция общения | `message-station.mp4` | `message-station.ru.vtt` | Безопасные ответы и обращение за помощью |

Используйте только заранее проверенные локальные файлы. Удалённые URL не нужны.

## Границы приватности

- В заданиях нет полей для имени, адреса, школы, телефона, настоящего пароля или кода подтверждения.
- Парольная механика использует только готовые учебные карточки.
- Чат предлагает фиксированные ответы и не отправляет введённый пользователем текст.
- В `localStorage` сохраняются режим, текущий экран, прогресс по районам и только разрешённые идентификаторы выбранных фиксированных ответов чата. Свободного текста в чате нет; лишние поля и данные старых, не входящих в демо маршрутов отбрасываются.
- Приложение не запрашивает доступ к микрофону и не обращается к внешним сервисам.

**Current demo: conversation is a deterministic training mock; no API key, microphone, or network is required.** В сокращённой версии нет голосового режима, OpenAI/Realtime-интеграции и конструктора итоговой карточки.

## Проверка

```bash
cd cyber-expedition-demo
npm test
npm run test:e2e
```

E2E-проверка запускает локальный сервер самостоятельно и проверяет детский маршрут, режим просмотра, клавиатуру, размеры `1280×800` и `390×844`, отсутствие горизонтального переполнения и ошибок браузера или внешних запросов.
