# КиберМиссии

Интерактивный wow-прототип цифровой гигиены для детей 7–10 лет. Внутри три короткие истории:

- «КиберКот» — как распознать ссылку-ловушку;
- «Цифровой лес» — какие личные данные нельзя отправлять незнакомцам;
- «Космопатруль» — почему пароли и коды нельзя сообщать под давлением.

Прототип не требует регистрации, не содержит реальных ссылок, не собирает данные и не обращается к внешним сервисам.

## Запуск

Из папки проекта:

```bash
node scripts/serve.mjs
```

Затем откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Проверка

Модульные тесты:

```bash
node --test tests/*.test.mjs
```

Браузерный маршрут в среде Codex:

```bash
NODE_PATH=/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules node tests/e2e.mjs
```

Браузерный тест проходит все три миссии, проверяет неправильный ответ и повтор, сохранение прогресса, сброс, клавиатуру, мобильную ширину, доступные названия элементов, отсутствие внешних запросов и ошибок консоли.

## Рекомендуемый показ заказчику

1. На главном экране быстро показать, что доступны три разных мира.
2. Полностью пройти «КиберКота», включая один неправильный ответ и доброжелательную повторную попытку.
3. Вернуться на главный экран и обратить внимание на полученный значок.
4. Открыть две остальные миссии, чтобы показать масштабирование общего игрового движка.

## Озвучивание

Если браузер поддерживает встроенный синтез речи, на сюжетном экране появляется кнопка «Послушать героя». Игра остаётся полностью понятной и без звука.

## Размещение

Это статическое приложение: для публикации достаточно перенести содержимое папки на любой HTTPS-хостинг статических файлов. Серверная часть и секретные ключи не нужны.
