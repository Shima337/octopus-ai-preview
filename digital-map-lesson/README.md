# «Карта цифрового мира»

Самостоятельное интерактивное занятие по цифровой безопасности для детей 7–10 лет. Полное прохождение занимает примерно 30–40 минут. Регистрация, ввод имени и другие личные данные не нужны.

## Как запустить

```bash
npm install
npm start
```

После запуска открыть `http://127.0.0.1:4174/`.

Прогресс сохраняется только в браузере на этом устройстве. Кнопка «Пройти с другой картой» очищает его после подтверждения.

Без API-ключа весь урок работает в деморежиме. Голосовое задание в нём использует готовые безопасные реплики и честно обозначено как демонстрация.

## Что входит в занятие

1. Видеовступление или работающий текстовый экран-заглушка.
2. Шесть карточек «безопасно / опасно / нужно разобраться».
3. Конструктор личной карты из шести типов цифровых мест.
4. Ветвящийся чат, где игровой незнакомец постепенно пытается выведать личные данные.
5. Три персональных расследования по выбранным местам.
6. Один голосовой разговор с цифровым наставником и разбор трёх навыков.
7. Игра на порядок действий «Щит путешественника».
8. Финальная карта, четыре кристалла и памятка-алгоритм.

## Как включить настоящий голосовой разговор

Скопировать пример настроек:

```bash
cp .env.example .env
```

В созданном `.env` заполнить только серверный ключ:

```dotenv
OPENAI_API_KEY=ваш_ключ
```

После перезапуска `npm start` кнопка «Поговорить голосом» станет доступна. Браузер соединяется с OpenAI Realtime через WebRTC, но стандартный API-ключ остаётся на сервере и не передаётся клиентскому коду. Модель, голос и модель итоговой оценки при необходимости меняются переменными из `.env.example`.

Если микрофон запрещён, WebRTC недоступен или внешний сервис не отвечает, урок предлагает перейти в деморежим без потери уже пройденных этапов.

## Как добавить видео

Положить ролики и субтитры в папку `media/`, затем в `src/content.js` заполнить поля `source` и `captions` у нужного объекта в массиве `VIDEOS`:

```js
{
  id: 'digital-day',
  // остальные поля не меняются
  source: './media/digital-day.mp4',
  captions: './media/digital-day.ru.vtt',
}
```

Рекомендуемые имена файлов:

- `digital-day.mp4` — «Один цифровой день», 60–90 секунд;
- `too-good-gift.mp4` — «Слишком хороший подарок», 25–40 секунд;
- `file-or-virus.mp4` — «Полезный файл или вирус?», 25–40 секунд;
- `joke-not-funny.mp4` — «Шутка, которая перестала быть смешной», 30–45 секунд;
- `safer-map.mp4` — «Моя карта стала безопаснее», 30–45 секунд.

Для каждого ролика желательно передать `.mp4` или `.webm` и русские субтитры `.vtt`. Если файл отсутствует, приложение автоматически показывает аккуратную заглушку и позволяет продолжить.

## Проверка

```bash
npm test
npm run test:e2e
```

Полный браузерный тест проверяет карточки, карту, новый чат, три прежних расследования, голосовую демоверсию, щит, четыре кристалла, сохранение прогресса, перезапуск, мобильную ширину, клавиатуру и отсутствие внешних запросов. Все вызовы OpenAI в автоматических тестах подменяются и не расходуют API-квоту.

Реальный голос дополнительно проверяется вручную после установки ключа: разрешить микрофон, дождаться ответа наставника, проверить выключение/включение микрофона, завершение разговора, итоговый разбор и откат в деморежим при отключении сети.

## Приватность детей

Приложение не просит имя, адрес, школу, телефон, логин или пароль. Текстовый чат использует только готовые вымышленные реплики. Аудио, SDP и история разговора не записываются на диск нашим сервером; серверные тела запросов не логируются.

Для реального использования с детьми младше 13 лет или применимого возраста цифрового согласия заказчик должен обеспечить необходимые согласия и требования детской приватности. Если могут обрабатываться персональные данные детей, официальное руководство OpenAI требует заранее настроить Zero Data Retention. До выполнения этих условий живой режим следует демонстрировать взрослым либо использовать только вымышленные фразы без персональных данных.
