# «Карта цифрового мира»

Самостоятельное интерактивное занятие по цифровой безопасности для детей 7–10 лет. Полное прохождение занимает примерно 25–35 минут. Регистрация, ввод имени и другие личные данные не нужны.

## Как запустить

```bash
npm start
```

После запуска открыть `http://127.0.0.1:4174/`.

Прогресс сохраняется только в браузере на этом устройстве. Кнопка «Пройти с другой картой» очищает его после подтверждения.

## Что входит в занятие

1. Видеовступление или работающий текстовый экран-заглушка.
2. Шесть карточек «безопасно / опасно / нужно разобраться».
3. Конструктор личной карты из шести типов цифровых мест.
4. Три персональных расследования по выбранным местам.
5. Игра на порядок действий «Щит путешественника».
6. Финальная карта, четыре кристалла и памятка-алгоритм.

## Как добавить видео

Положить ролики и субтитры в папку `media/`, затем в `src/content.js` заполнить поля `source` и `captions` у нужного объекта в массиве `VIDEOS`:

```js
{
  id: 'digital-day',
  // остальные поля не меняются
  source: './media/digital-day.mp4',
  captions: './media/digital-day.ru.vtt',
}
```

Рекомендуемые имена файлов:

- `digital-day.mp4` — «Один цифровой день», 60–90 секунд;
- `too-good-gift.mp4` — «Слишком хороший подарок», 25–40 секунд;
- `file-or-virus.mp4` — «Полезный файл или вирус?», 25–40 секунд;
- `joke-not-funny.mp4` — «Шутка, которая перестала быть смешной», 30–45 секунд;
- `safer-map.mp4` — «Моя карта стала безопаснее», 30–45 секунд.

Для каждого ролика желательно передать `.mp4` или `.webm` и русские субтитры `.vtt`. Если файл отсутствует, приложение автоматически показывает аккуратную заглушку и позволяет продолжить.

## Проверка

```bash
npm test
```

Полный браузерный тест находится в `tests/e2e.mjs`. Он проверяет прохождение, ошибочные попытки, четыре кристалла, сохранение прогресса, перезапуск, мобильную ширину, клавиатуру и отсутствие внешних запросов.
