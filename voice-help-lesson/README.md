# «Голос цифровой безопасности»

Отдельный голосовой урок для детей 7–10 лет. За 10–12 минут ребёнок тренируется объяснять доверенному взрослому три цифровые ситуации: подозрительный подарок, просьбу о личных данных и травлю в чате.

## Запуск без API-ключа

```bash
npm start
```

Открыть `http://127.0.0.1:4175/`. Приложение покажет «Демо-режим»: весь урок можно пройти текстом, а после неудачной отправки записи — использовать безопасный пример расшифровки.

## Подключение OpenAI

1. Скопировать `.env.example` в `.env` внутри папки урока.
2. Заполнить переменную только в локальном `.env`:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_TRANSCRIBE_MODEL=gpt-transcribe
PORT=4175
```

3. Перезапустить `npm start`.
4. В верхней панели должен появиться зелёный статус «AI распознавание».

Ключ нельзя вставлять в `index.html`, `src/*.js`, консоль браузера или отправлять вместе со ссылкой на приложение. `.env` исключён из Git. Браузер отправляет короткую запись только нашему `/api/transcribe`; сервер добавляет ключ при обращении к OpenAI.

## Как работает запись

- Микрофон включается только после нажатия ребёнком.
- Запись автоматически останавливается через 20 секунд.
- Поддерживаются `webm`, `ogg`, `mp4/m4a`, `mp3` и `wav`; максимальный размер запроса — 4 МБ.
- Аудио обрабатывается в памяти и не записывается на диск.
- Сервер не логирует аудио, расшифровку или ключ.
- После распознавания текст можно исправить до анализа.
- Если микрофон или API недоступны, доступны текст и безопасный пример.

## Требования при работе с детьми

Интерфейс специально напоминает не называть настоящее имя, школу, адрес, телефон, логин или пароль. Для демонстрации заказчику до оформления требований детской приватности используйте голос взрослого и вымышленные фразы.

Перед реальным использованием с детьми младше 13 лет заказчику необходимо проверить применимые согласия и требования законодательства. Официальное руководство OpenAI указывает, что обработка персональных данных детей младше 13 лет или применимого возраста цифрового согласия требует предварительного включения Zero Data Retention: [Under 18 API Guidance](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance).

Техническая документация распознавания: [File transcription](https://developers.openai.com/api/docs/guides/speech-to-text).

## Проверка

```bash
npm test
NODE_PATH=/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules npm run test:e2e
```

Автоматические проверки не обращаются к OpenAI и не расходуют средства. Они используют подменённую внешнюю границу, но настоящий сервер, маршруты, анализатор и интерфейс.

## Проверка реального микрофона

1. Запустить сервер с ключом и убедиться, что статус зелёный.
2. Открыть урок в целевом Chrome по `http://127.0.0.1:4175/`.
3. Разрешить микрофон только этому локальному сайту.
4. Произнести вымышленную фразу длительностью 5–10 секунд.
5. Проверить расшифровку и исправление одного слова.
6. Проверить отказ в разрешении: урок должен предложить текст, а прогресс не должен потеряться.
7. После проверки удалить значение ключа из `.env`, если компьютер используется другими людьми.
